# FC 在线模拟器

基于 [jsnes](https://github.com/bfirsh/jsnes) 2.0.0（Apache-2.0）的纯静态网页 NES 播放器，UI 参考「小霸王」掌机造型，支持桌面键盘和移动端触控。无需构建。

## 运行

```bash
cd nes-player
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

必须通过 http 访问（`file://` 下 `fetch` 读不到 ROM 和 `games.json`）。

## 添加游戏

1. 把你合法拥有的 `.nes` 文件放进 `roms/`。
2. 在 `games.json` 登记，格式为 `{ "分类": [["显示名", "ROM 路径"]] }`：

```json
{
  "示例": [
    ["我的游戏", "roms/mygame.nes"]
  ]
}
```

第一项会自动载入。也可以点工具栏的文件夹图标，直接选择本地 ROM 载入。

## 按键

默认键位（点工具栏的键盘图标可查看和修改）：

| 动作 | 玩家 1 | 玩家 2 | 触屏（玩家 1） |
|---|---|---|---|
| 上 / 下 / 左 / 右 | W / S / A / D | ↑ / ↓ / ← / → | 左侧十字键（8 向，可滑动） |
| A | K | . | A |
| B | J | , | B |
| 连发 A | I | / | - |
| 连发 B | U | ; | - |
| Select | C | 右 Shift | Select |
| Start | B | Enter | Start |
| 存档 | Q | | - |
| 读档 | E | | - |

### 自定义按键

- 点工具栏的键盘图标打开设置面板，面板里有玩家 1、玩家 2 两列，另有存档、读档两个键。
- 点某个按键格后按下新按键即可修改，Esc 取消。已修改的格子高亮（颜色随配色变化），并在下方小字标出默认值；“恢复默认”会还原全部。
- 新按键已被其他动作占用时，两个动作会互换按键，不会出现一个键对应两个动作。
- 设置保存在名为 `nes_keys` 的 Cookie 中（只存与默认值不同的项，有效期 1 年），不经过服务器。Cookie 被禁用时，修改只在本次打开期间有效，面板会提示。
- 打开面板期间游戏暂停，关闭后继续。
- 按的是键盘物理位置（`KeyboardEvent.code`），不随输入法或键盘布局变化；面板里的字母按 QWERTY 位置显示。
- 屏幕上的触控按钮固定对应玩家 1，不受自定义影响。

## 存档

- 按 Q 存档、按 E 读档（可在设置面板中修改），每个游戏 1 个存档位，提示显示在屏幕顶部。
- 存档保存在浏览器的 IndexedDB 中，不经过服务器；刷新页面、重启浏览器后仍在。
- 存档按 ROM 内容的哈希区分：不同游戏互不覆盖，同一个 ROM 从“本地文件”载入也能读到同一份存档。
- 换浏览器、换设备、清除站点数据后存档不会保留。
- 存档只保存模拟器状态，不含 ROM；读档前需要先载入同一个游戏。
- 存档约 1.2 ~ 1.5 MB，仅在存档时写入一次。

## 配色

点工具栏的调色盘图标，依次切换配色，屏幕顶部会提示当前名称。选择记在名为 `nes_theme` 的 Cookie 里（有效期 1 年），刷新后保留。

| 序号 | 名称 | 风格 |
|---|---|---|
| 1 | 红白机经典（默认） | 米白机身、红色外框、黑色按键，参考日版红白机 |
| 2 | 红白机灰机身 | 浅灰机身、深灰外框、黑色按键，红色点缀，参考美版 NES |
| 3 | 黑白极简 | 黑白灰，白色按键黑边，无彩色 |
| 4 | 黑红夜间 | 深色机身，红色强调，适合暗环境 |
| 5 | 经典蓝（原版） | 最初的蓝色配色，用于对比 |

要增删主题：在 `css/style.css` 开头复制一份 `:root[data-theme="..."]` 变量块并改色值，再在 `js/app.js` 的 `THEMES` 数组里加一项 `['名称', '显示名']` 即可。想固定某一套默认配色，把它的变量块改成 `:root` 默认值（目前默认是 famicom）。

## 全屏

- 点工具栏的全屏图标进入全屏；全屏时只显示游戏画面，背景全黑，画面保持 256:240 比例并放到最大（横屏高度顶满、竖屏宽度顶满，多余部分留黑边）。
- 全屏时工具栏、十字键、A/B 等触控按钮都会隐藏；键盘操作、存档/读档及其屏幕提示照常工作。
- 按 Esc 退出全屏（浏览器自带），退出后恢复原界面。
- 全屏时底部有缩放选择条：`1X`、`2X` … `NX`、`最大`。N 是当前窗口能放下的最大整数倍（画面 256×240 乘以倍数，宽高都不能超出窗口）。整数倍下画面居中，用最近邻缩放，像素边缘保持锐利；`最大` 为等比铺满，边缘会略平滑。默认是 `最大`。
- 选择条无操作 2.5 秒后淡出，移动鼠标或触摸屏幕会重新出现。
- 窗口大小变化时，N 和按钮会重新计算；所选倍数超出新窗口时临时降到当前最大倍数，窗口变大后会恢复。窗口放不下 1 倍时只剩 `最大`。
- 所选倍数在本次打开页面期间保留（退出再进入全屏仍沿用），刷新页面后恢复为 `最大`，不写入 Cookie。
- 不支持元素全屏的浏览器（如 iPhone 上的 Safari）不会显示全屏图标。
- 触屏设备进入全屏后没有触控按钮可用，更适合外接键盘或手柄时使用。

## 目录

```
index.html      页面
css/style.css   样式（横屏 / 竖屏自适应）
js/app.js       主循环、音频、ROM 加载、键盘与触控
lib/jsnes.min.js
games.json      游戏列表
roms/           ROM 文件（自行放置）
```

## 说明

- jsnes 支持的 mapper 有限，不支持的 ROM 会提示“ROM 无效或暂不支持”。
- 声音需要用户先操作一次页面（点击或按键）才会出声，这是浏览器自动播放策略的要求。
- 画面使用 `<canvas>` 2D 绘制，音频使用 `ScriptProcessorNode` 环形缓冲播放。
